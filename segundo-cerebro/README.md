# Segundo cerebro

Sistema personal de tareas, proyectos y documentación, organizado con el método **PARA** y trabajado en **sprints semanales** (metodología ágil).

## Dónde vive cada cosa

| Qué | Dónde |
|---|---|
| Tareas (estado, prioridad, check-ins) | Tablero **Mi Segundo Cerebro** (página de Claude, base de datos `tasks`) |
| Capturas rápidas (texto o voz) | Tablero → "Capturar", colección `inbox`; Claude las convierte en tareas |
| Notas y documentación | Esta carpeta |
| Revisiones semanales (retro + métricas) | `revisiones/AAAA-Wnn.md` |

## Carpetas

- `00-bandeja/` — lo que entra sin procesar (textos, transcripciones de audios).
- `01-proyectos/` — cosas con fin y entregable (ej. cuadernos de la mentoría en Claude).
- `02-areas/` — responsabilidades continuas: finanzas e impuestos, carrera, contenido (guiones/grabaciones), trámites.
- `03-recursos/` — material de referencia.
- `04-archivo/` — lo terminado o inactivo.
- `revisiones/` — una nota por semana.

## Ritmo

1. **Captura**: todo lo que aparezca va a la bandeja (texto, dictado o audio).
2. **Procesar**: Claude identifica tareas, les asigna proyecto/área, prioridad y fecha.
3. **Check-in diario**: ¿avanzaste? Sí / No / Bloqueada / Terminada.
4. **Revisión semanal**: comprometidas vs. hechas, tareas arrastradas, bloqueos y plan de la semana siguiente.
